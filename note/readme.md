# the MiniDrive course

# 设计需求
最近买了新相机后，拍了好多照片还有视频，硬盘不够了，刚好有云服务器
，计算要么多个服务器，要么内网穿透，然后把windows服务器访问

# 功能需求

1.照片上传，批量上传，连拍可以存储，可以批量读取
2.视频上传，下载
3.在线预览照片和视频

# 性能需求
1. 50~100并发连接
2. 多客户端同时上传下载
3. 大文件稳定传输
4. 服务端不卡死
